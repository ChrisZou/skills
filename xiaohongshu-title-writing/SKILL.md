# 小红书爆款标题创作

## 核心能力

快速生成符合小红书平台特点的高点击率标题，帮助内容获得更多曝光和互动。输入一个视频脚本，输出「封面文字 + 标题」组合，每组附原理分析。

## 标题创作流程

### 第 1 步：理解内容核心

先回答四个问题：核心卖点是什么、目标受众是谁、内容类型是什么、预期效果是种草 / 教程 / 分享 / 避坑中的哪种。

**多场景内容的主题选择。**如果视频讲的是 N 个场景或功能，标题和封面不能只取其中一个场景当主题，否则用户被单一场景吸引点进来发现只占一小部分，影响完播。要围绕整体主题起：产品本身、「覆盖多场景」这件事、整体评价、核心升级点；善用数字罗列体现广度；单个场景只能作举例佐证。例外是某个场景明显是全片绝对核心时才可以它为主题，但仍要体现整体感。

### 第 2 步：明确标准

**核心传达要求（硬性）。**每条标题和封面文字必须传达以下四种感受中的至少一种：价值感（看完能得到什么，如「十分钟学会」「N 大场景全面实测」）、情绪感（惊喜 / 震撼 / 慌张 / 破防等具体情绪）、好奇悬念感（用「到底 / 居然 / 谁能想到」留信息缺口，但不能空洞）、反差冲突感（前状态到后状态、常识到反常识）。一种都没有的必须重写，不允许进入交付。

**给人的感觉（硬性）。**每条标题至少满足一项：够不够大胆（有明确敢说的判断，不是模棱两可的介绍）、够不够新鲜（换个产品名套不上别的笔记，有只属于这条内容的细节）、够不够勾人（读完会冒出一个想知道答案的问题）。三项都不满足的必须重写。这条检查和上面的四种感受是两道独立关卡。

### 第 3 步：选择标题公式

从 `references/title-formulas.md` 里选一个或多个公式。十个主公式是：数字+效果+场景、反差对比、痛点提问、避坑指南、好奇悬念、身份标签+需求、限时紧迫感、权威背书、详细数据、情绪共鸣。此外还有七种方法：具体的数字、消极偏见、群体点名、问题点名、潜在益处、自信与信念、警告与告诫。注意这些方法都只是参考手段，不是硬性要求也不是目的，目标还是实现第 2 步提到的核心传达要求和给人的感觉的要求。

### 第 4 步：控制标题长度

**长度（硬性）。**标题不超过 20 个字。计算规则：1 个汉字算 1 字；英文字母和数字每 2 个字符算 1 字，向上取整；标点、emoji、分隔符不计。每条写完必须核算，超了必须删减。

### 第 5 步：封面文字设计

封面文字给出核心的内容点或问题点就行了。同样，也要给用户价值感、好奇心、悬念感、情绪感或反差感。比如：

- 一天工作 一小时干完（核心价值）
- 关税全退了？（好奇心：真的吗？退了多少？为什么？）
- 前痞幼编导，教你做视频（价值感：前痞幼编导？那肯定很厉害，看完这个视频一定能学到东西）
- 奶茶之王（悬念：到底是谁呢？）



### 第 6 步：生成多个版本

至少 3 到 5 个不同角度的版本（直白 / 悬念 / 情绪 / 换角度 / 换公式），命令模式下固定 20 组。定稿前每组的标题和封面文字都过第 2 步的两道检查：核心传达要求至少一种、「给人的感觉」至少一项。任一道没过必须重写。

## 输出格式

必须输出 HTML 文件。流程是：读取 `references/html-output-template.html`，把所有 `{{PLACEHOLDER}}` 替换为实际内容，写入 `output/标题-{视频主题}.html`，然后用 `open` 在浏览器打开。

模板里的占位符：VIDEO_TOPIC（视频主题）、SUBTITLE（副标题）、KEY_POINT_1 到 4（脚本核心卖点）、CARD_COUNT（卡片总数）；每张卡片有 CARD_NUM、FORMULA_TAG、COVER_LINE_1 到 3（按封面文字实际行数增减，多余的 div 删掉）、TITLE_TEXT、ANALYSIS_TEXT；底部综合推荐区有 TOP_PICKS 和 BY_FOCUS 两个列表。

**推荐标注。**评估后选 3 到 5 个最强方案：卡片 class 改为 `card recommended`，并在 card-header 内加 `<span class="recommended-badge">⭐ 推荐</span>`。

**综合推荐区。**「优先测试」列推荐卡片编号加一句理由；「按内容侧重选择」按强调方向分组（性价比 / 场景 / 趣味性等）。

## 最佳实践与常见问题

标题必须真实反映内容，用受众的语言，多试公式，关注流行表达，不做标题党，遵守平台规范。常见问题的处理：标题太长就按字数规则删减、把重要信息放前面；判断好坏时清晰优于机巧、利益优于功能；不能照抄别人标题，只学公式；标题完整但平淡，先查四种感受再过「给人的感觉」，纯功能罗列两道都过不了；满足四种感受仍要过「给人的感觉」，因为前者管传达了什么，后者管表达得够不够有力。

绝对不要标题党。
